# Stage 5 implementation plan

Goal: connect whole Stage 4 combined graphs, one per year, in a common world
coordinate frame. Tile indices and source-pixel coordinates never establish
cross-year identity. Work in the existing workspace; preserve upstream artifacts.

Architecture: separate coordinate conversion/registration, region correspondence,
and graph persistence. Use existing NumPy, Rasterio, Shapely, OpenCV, and SciPy.
No pretrained model downloads or segmentation reruns. Default matching is an
auditable engineering baseline, not a reproduction of a learned paper.

- [x] Add behavioral tests for shifted origins, different CRSs, missing metadata,
  class changes, split/merge, ambiguous matches, partial coverage, and persistence.
  Run them first and confirm missing Stage 5 is the failure.
- [x] Implement source affine [a,b,c,d,e,f] conversion and projected metre CRS
  validation. Support robust affine registration from supplied control points
  and optional SIFT image matches. Reject degenerate or inaccurate fits.
- [x] Implement spatial-index candidates, polygon/shape/neighborhood similarity,
  unmatched-aware assignment, conservative lineage events, and coverage states.
- [x] Build the time-expanded graph, preserve spatial edges, propagate track IDs
  only through one-to-one correspondences, and save JSON, arrays, WGS84 GeoJSON,
  evidence reports, a preview, and a checksum-bound manifest. Add CLI and docs.
- [x] Run focused and available regression tests; audit real four-tile world
  conversion. Record that no second-year input exists; never fabricate one as
  observational evidence.

Review focus: affine coefficient order; geographic degrees versus metres;
clipped objects versus real area change; unknown classes versus transitions;
failed registration and equal-score ambiguity; stale inputs and corrupt exports.

Validation: the Stage 5 unittest suite covers the listed behavior plus file-based
CLI runner integration and SIFT raster registration. Full upstream pytest suite
could not run: pytest is absent and network restrictions prevented installation.
The real 2005 four-tile graph's 1,457 polygons yield 621,936.64 square metres,
matching 0.8-m source pixel area. No second-year graph is locally available.

Review correction: ambiguity now includes IoU-eligible alternatives below the
acceptance-score threshold. Registration hull support is measured against the
selected observed footprint, rejecting distant control-point clusters.
