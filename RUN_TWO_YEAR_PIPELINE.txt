SATELLITEGRAPH: SINGLE IMAGE, FULL FOLDER, AND TWO-YEAR COMPARISON
Run these PowerShell commands from the SatelliteGraph repository root.
The Python environment needs the project dependencies and configured model weights.

$python = '..\.venv\Scripts\python.exe'

1. PROCESS EXACTLY ONE PNG

& $python -m src image run --image 'tiles17_23/2017/tile_00000.png' --year 2017 --output 'artifacts/single_2017_tile_00000'

--image selects the only PNG to process, even if its folder contains other PNGs.
The command runs segmentation, automatic refinement and noise cleanup, the tile
graph, and the annual graph. Its main outputs are:

artifacts/single_2017_tile_00000/run.json
artifacts/single_2017_tile_00000/full_image_with_graph.png
artifacts/single_2017_tile_00000/full_image_with_analysis_graph.png

If the PNG's folder contains metadata.csv and a matching georeferenced GeoTIFF,
the command uses them for source/global coordinates. If the folder has only
PNGs, it still runs the single image: its graph uses local image pixels with
the upper-left corner at (0, 0). A PNG alone does not reveal its original
position, pixel size in metres, or map CRS.

2. PROCESS EVERY PNG IN EACH YEAR'S FOLDER

& $python -m src folder run --folder 'tiles17_23/2017' --year 2017 --output 'artifacts/annual_2017'
& $python -m src folder run --folder 'tiles17_23/2023' --year 2023 --output 'artifacts/annual_2023'

Each command runs segmentation, automatic refinement and noise cleanup,
refinement validation, one graph per tile, and a combined spatial graph for
that year. Check that both run.json files have status "complete":

artifacts/annual_2017/run.json
artifacts/annual_2023/run.json

The full-image graph overlays are:

artifacts/annual_2017/full_image_with_graph.png
artifacts/annual_2023/full_image_with_graph.png

The example tiles17_23/2017 and tiles17_23/2023 folders in this workspace
each have PNG tiles, metadata.csv, and a matching selection_<year>.tif.
For ANY other full folder, folder run requires tile_name, x0, and y0 in
metadata.csv and a matching georeferenced source GeoTIFF. If these files are
stored elsewhere, pass --metadata 'path/to/metadata.csv' and
--source-raster 'path/to/source.tif' to that year's folder run command.
The PNG pixels must match the corresponding GeoTIFF windows. A folder of
only PNGs cannot be combined accurately into one spatial graph because tile
positions and the map coordinate system are missing. The original tiling
metadata and georeferenced raster must be recovered or regenerated from the
original georeferenced image; they cannot be inferred reliably from filenames.

3. BUILD THE SPATIOTEMPORAL GRAPH FROM TWO COMPLETED YEARLY RESULTS

& $python -m src folder compare --first 'artifacts/annual_2017' --second 'artifacts/annual_2023' --registration-json 'tiles17_23/registration_2017_2023.json' --output 'artifacts/spatiotemporal_2017_2023'

--first is the earlier completed annual run; --second is the later one.
The example registration JSON aligns the two years. For other georeferenced
yearly inputs without measured registration control points, replace
--registration-json '...' with --register-images to estimate alignment from
the source images. Do not pass both options. Both yearly graphs must have a
real georeference and a projected metric target CRS; PNG-only local-pixel runs
cannot be used with this temporal comparison command.

Inspect:

artifacts/spatiotemporal_2017_2023/run.json
artifacts/spatiotemporal_2017_2023/01_temporal_graph/temporal_graph.png
artifacts/spatiotemporal_2017_2023/01_temporal_graph/graph.json
artifacts/spatiotemporal_2017_2023/01_temporal_graph/changes.geojson
artifacts/spatiotemporal_2017_2023/01_temporal_graph/report.json

The comparison displays percentage progress while matching source nodes,
finding cross-year overlaps, and assessing change groups. Add --no-progress
to suppress these bars. Completed annual output folders can be moved or copied
together with their stage4 artifacts; the command verifies those artifacts
against the checksums in each local Stage 4 manifest.

The temporal PNG is a graph overview. Review candidate changes against the
yearly image overlays and changes.geojson; construction and demolition are
model-derived change labels, not independently verified physical events.

4. COMPARE ONE COMPLETED PNG OUTPUT PER YEAR

If both output folders were created with "image run" (one PNG per folder):

& $python -m src image compare --first 'artifacts/single_2013' --second 'artifacts/single_2023' --output 'artifacts/one_tile_2013_2023'

If both output folders contain a full annual run, select one saved PNG:

& $python -m src image compare --first 'artifacts/annual_2013_updated' --second 'artifacts/annual_2023_updated' --tile 'tile_00000.png' --output 'artifacts/temporal_tile_00000_2013_2023'

This uses the completed graphs and saved tile PNGs; it does not rerun
segmentation or refinement. The selected annual graph is clipped to the
one tile window. A real source georeference is required in both outputs.
The preview places the earlier satellite image above the later one at
their mapped positions, with small nodes and blue matched-region links.
Class-specific known-land-cover change links are colored in the gap so the
imagery stays readable. Unknown-class transitions are omitted from the PNG
preview; every edge remains in graph.json and changes.geojson.

Use a new output folder when changing an input, year, or configuration.
